Подключение AI

AI получает не сырые выгрузки, а компактные задачи и безопасные инструменты.

Так дешевле, быстрее и безопаснее: метрики считает код, правила находят аномалии, LLM объясняет, приоритизирует и пишет рекомендации.

1

Импорт данных

Yandex Direct API и Метрика загружают кампании, расходы, конверсии, запросы и статусы.

2

Rule Engine

Backend считает CPA, CTR, CR, динамику, расход без конверсий и выбирает только важные кейсы.

3

AI Layer

Модель получает короткий JSON, объясняет проблему, предлагает действия и оценивает риск.

4

Approval

Пользователь подтверждает черновик, только после этого backend применяет изменения через API.

Как сделать дешевле

Три режима AI вместо одного дорогого “супермозга”.

Сильную модель используем только там, где нужна стратегия. Всё остальное — правила, шаблоны, кэш и дешёвые модели.

0 ₽ на LLM-запрос

Расчёт CPA, CTR, CR, сравнение периодов, поиск расхода без конверсий, UTM-проверки и базовые алерты выполняет backend.

Для массовых операций

Классификация поисковых запросов, черновики объявлений, короткие объяснения и отчёты по шаблону идут через недорогую модель и кэшируются.

Только для сложных задач

Стратегический аудит, разбор причин падения, риск-чек перед массовым применением и консультационный чат используют сильную модель.
